## Publication scope

The public site source is limited to the files linked above and this homepage.
It intentionally omits experiment results, exploratory data analysis (EDA),
data files, figures, raw traces, provider artifacts, DeepSWE-derived material,
and unresolved LLMLingua2 material. Those exclusions apply even when a file is
tracked in the public repository or has a repository publication grade.

The site is a rights and publication boundary, not an experiment report. It
makes no benchmark, billing, compression-quality, model, or provider claim.
