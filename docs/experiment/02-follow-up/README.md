# 2차 연구: Cache 재사용과 SWE-Lancer 후속 실행

이 폴더는 [1차 예비 비교](../01-preliminary-comparison/README.md) 뒤에 수행한 두 후속
실행을 묶는 현재 문서 입구다. 여기서 **2차 연구**는 문서를 나누기 위한 조직 단위다.
Cache 재사용과 SWE-Lancer는 질문과 분모가 다른 독립 하위 연구이며 서로의 효과나
품질을 비교하지 않는다.

## 먼저 읽을 결과

### Cache 재사용

**질문과 조건.** `none`과 `squeez`, 재사용 수준 `0 → 1 → 2`, 셀마다 고정 5과제,
동시성 `1`로 캐시 비교에 쓸 유효 사이클을 확보할 수 있는지 물었다.

**관측.** 제공자 호출 18회는 성공했지만 첫 사이클이 요청 접두부 검증에서 무효가
됐다. 유효 사이클은 `0`개다.

**이 결과가 말하지 않는 것.** Cache 효과, 캐시 미스율, 절감액, 재사용 대비, 안정성,
조건별 품질 차이는 계산하거나 비교하지 못했다. 자세한 조건과 분모는
[Cache 재사용 요약](cache-reuse/README.md)에 있다.

### SWE-Lancer

**질문과 조건.** 후보 `28565_1001` 하나를 고정하고 실행 1회, 동시성 `1`, 재시도
`0`으로 제공자·격리 실행 환경·채점기를 잇는 유효한 프로토콜 실행 기록을 만들 수
있는지 물었다.

**관측.** 계획은 1회였지만 실행 결과 묶음 2개가 생겼고, 두 번 모두 격리 실행
환경이 시작되는 동안 시간 초과가 났다. 제공자와 채점기 호출 전이었으며 유효
프로토콜 실행 기록은 `0`개다.

**이 결과가 말하지 않는 것.** 과제 통과 여부, 모델 품질, 통과율, 순위, 안정성,
대표 비용은 측정하지 못했다. 자세한 조건과 실패 경계는
[SWE-Lancer 요약](swe-lancer/README.md)에 있다.

여기서 관측 결과인 `0`은 유효 사이클과 유효 프로토콜 실행 기록의 개수에만
해당한다. 문서 안의 모든 `0`이 관측값이라는 뜻은 아니다. 재시도 `0`은 설정값이고,
계산한 API 비용의 0은 제공자 사용량에서 얻은 계산값이다. `unknown`,
`not_applicable`, `not_measured`는 각각 이 기록에서 알 수 없음, 적용 대상 아님,
측정하지 않음을 뜻한다. 서로 바꾸어 읽지 않는다.

## 읽는 순서

1. 이 페이지에서 두 질문과 결론의 범위를 확인한다.
2. 각 한국어 하위 페이지에서 조건, 관측, 가능한 설명, 한계를 짧게 읽는다.
3. 수치와 증거 해시를 인용할 때는 각 페이지가 연결한 영어 전체 보고서를 확인한다.

한국어 하위 페이지는 영어 전체 보고서의 **요약**이며 전체 번역이 아니다. 전체
보고서에는 측정 용어, 조건, 사용량, 비용, 안전 상한, 증거 해시와 정리 상태가
남아 있다.

## 역사 기록과의 경계

- `SWE-Lancer third-benchmark candidate`는 먼저 작성된 후보 검토의 역사적 표현이다.
  새 `03-` 실험 번호를 뜻하지 않는다.
- EDA round 1과 round 2는 1차 자료를 분류하고 검토한 단계다. 이 폴더의 두 후속
  실행과 같은 실험 번호로 다시 분류하지 않는다.
- 1차 실험 문서, 동결된 영어 snapshot, 복원된 한국어 원문, 기존 그림과 원시
  측정 계보는 이 폴더로 옮기지 않는다.

영어 현재 문서 입구는 [Follow-up study](../../../docs_en/experiment/02-follow-up/README.md)다.
