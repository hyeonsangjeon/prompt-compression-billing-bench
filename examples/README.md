# 실행 예제

- [`static/`](static/)은 외부 모델을 호출하지 않는 고정 입력 예제다.
- [`experiment/static.yaml`](experiment/static.yaml)은 정적 계약 결과 형식을 확인한다.
- [`experiment/native.yaml`](experiment/native.yaml)은 로컬 native 사전 검사를 설명한다.
- [`experiment/benchmark.yaml`](experiment/benchmark.yaml)은 Terminal-Bench 2.1
  단일 과제의 기본 무호출 확인과 명시적 실제 실행 경계를 고정한다.

실제 모델 호출 여부와 필요한 환경 변수는 각 YAML의 실행 모드와 루트
[빠른 시작](../README.md#try-it-in-five-minutes)을 함께 확인한다.
